# ArcJSON-Style
**This project does not receive updates.**

ArcJSON-Style is a tool that provides a graphical user interface (GUI) for creating ArcJSON styling configurations for points, lines, and polygons. This tool simplifies the process of generating JSON configuration files for GIS applications.

## Features

- **Point Styling**: Customize size, fill color, outline color, and symbol type.
- **Line Styling**: Define line width, color, and style.
- **Polygon Styling**: Configure fill color, outline color, line style, and pattern.
- **User-Friendly Interface**: Intuitive tabs for each geometry type.
- **Save Configurations**: Export generated JSON files for use in GIS applications.

## Usage

1. Launch the application.
2. Navigate to the desired tab (Point, Line, or Polygon).
3. Input the required style parameters.
4. Click "Save" to export the JSON configuration file.

## Requirements

- Python 3.x
- Tkinter library
